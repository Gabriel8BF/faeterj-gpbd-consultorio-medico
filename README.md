# faeterj-gpbd-consultorio-medico
Implementação de banco de dados relacional em MySQL para gestão de clínica médica (pacientes, médicos, consultas, medicamentos e receitas) e resolução de 30 consultas SQL avançadas. Projeto avaliativo (Etapa 2) da disciplina de Gestão de Projetos de Banco de Dados na FAETERJ.
